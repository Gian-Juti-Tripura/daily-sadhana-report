==================================================
PART 1 — CORE PRODUCT VISION
==================================================

The current VOICE service system is maintained manually using a physical service-cycle chart.

Every day, the Internal Manager has to determine:

- Which member has which service
- Which member has multiple services
- Which member/service is absent
- Why a service is absent
- Whether a replacement is needed
- Then manually prepare and post an announcement in the WhatsApp group

The purpose of this application is to automate this entire workflow.

The application must automatically calculate the daily service cycle, display assignments, manage members and services, manage absences and replacements, generate WhatsApp announcements, and later automatically communicate through Telegram.

The VOICE application must become the single source of truth for the service system.

Messaging platforms must NEVER become the source of truth.
